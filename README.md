# dyrt

Source for the dyrt website, the studio behind [RoLens](https://github.com/Simon-commit/rolens).

The site is plain static HTML with no build step. It is hosted on Cloudflare Pages, which publishes every push to `main` automatically.

## Files

- `index.html`: the page, with its styles inline.
- `favicon.svg`: the browser tab icon.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.
