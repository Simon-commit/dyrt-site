Crowdfill vs Borang

An honest comparison of Crowdfill and Borang for submitting Google Forms multiple times: features, pricing and when each one is the better choice. Updated 9 November 2026.

Borang is the best-known Chrome extension for submitting Google Forms multiple times, with around 40,000 users. Its free version submits the same answers many times in one click, and randomized answers, speed control, scheduling and most other features are part of Borang Premium. Crowdfill does the same job with every feature free, and adds a crowd model that keeps each generated person's answers consistent.

When Borang is the better pick

If you need Microsoft Forms, Borang supports it and Crowdfill does not. Borang Premium also lists statistics such as Cronbach's alpha, which Crowdfill does not calculate.

When Crowdfill is the better pick

If you want realistic test data rather than the same answers repeated, Crowdfill's crowd model is the difference. Each response comes from a generated person with a mood, so ratings, recommendations and comments agree with each other, and the results look like a real survey. Everything is free, nothing passes through a server of ours, and the code is open for anyone to read.

Switching takes two minutes

  1. Add Crowdfill to Chrome.
  2. Open the same Google Form and click the Crowdfill icon. It reads the form itself, so there is nothing to fill in first.
  3. Pick a crowd, check the Preview, and send from the Run tab.

If you used Borang's answer import, Crowdfill reads a CSV too, such as a Google Forms response export, and matches the columns to questions automatically.

Questions

Is Crowdfill really free?

Yes. There is no paid tier. The optional AI crowd runs on your own Anthropic API key, so that part is paid to Anthropic, and only when you use it.

Can Crowdfill submit forms that need sign-in?

Only as you, once per account. It does not get around sign-in or one-response limits.
