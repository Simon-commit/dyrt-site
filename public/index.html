Flagship

RoLens

A Chrome extension that places live Rolimon's and RoUtility values directly inside Roblox trades, item pages and inventories. Values, RAP, demand and USD estimates appear where decisions are made, without resizing a single element of the page.

RoLens reads trade data with read-only requests and never sends, accepts or declines a trade on your behalf.

About

dyrt is the studio name of Simon, a developer focused on browser software for the Roblox trading community.

The work is published in the open so that anyone can read exactly what it does before installing it.

  • Open by defaultAll source code is public and released under the MIT licence.
  • No hidden accessNo analytics, no remote code and no requests beyond what each feature documents.
  • Quiet interfacesInformation appears in place, sized to the page, and never covers what it describes.
